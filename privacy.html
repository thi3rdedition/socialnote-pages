소셜노트

개인정보 처리방침

소셜노트는 사용자가 입력한 관계 기록을 기본적으로 사용자의 기기 안에 저장합니다. 1차 출시 버전은 계정, 광고, 추적, 원격 분석, 네트워크 백업 기능을 제공하지 않습니다.

홈 문의 및 지원

최종 갱신일: 2026-06-05

1. 앱이 다루는 정보

소셜노트는 사용자가 직접 입력하거나 선택한 다음 정보를 앱 안에서 다룹니다.

  • 카드 이름, 카테고리, 태그
  • 기본정보, 현재정보, 카드별 추가 항목
  • 노트 본문과 노트에 연결한 사진
  • 앱 테마, 목록 배치, 이름 노출 방식, 검색 이력 저장 여부 같은 앱 설정
  • 사용자가 직접 생성한 파일 백업 ZIP

2. 저장 위치

사용자가 입력한 카드, 노트, 사진, 설정은 기본적으로 사용자의 기기 안에 저장됩니다. 소셜노트는 1차 출시 버전에서 별도 계정을 만들거나 앱 데이터를 소셜노트 서버로 전송하지 않습니다.

3. 파일 백업

사용자가 설정 화면에서 파일 백업을 실행하면, 앱 데이터와 사진이 ZIP 파일로 만들어집니다. 이 백업 파일은 사용자가 직접 보관, 이동, 삭제하는 파일입니다.

백업 파일에는 사용자가 앱에 입력한 카드, 노트, 사진이 포함될 수 있으므로 다른 사람에게 공유하기 전에 내용을 확인해야 합니다.

4. 사진 접근

소셜노트는 사용자가 노트에 사진을 첨부할 때 iOS의 사진 선택 기능을 사용합니다. 앱은 사용자가 선택한 사진을 노트에 저장하기 위해 처리합니다.

5. 수집하지 않는 정보

1차 출시 버전 기준으로 소셜노트는 다음을 하지 않습니다.

  • 광고 또는 제3자 광고 SDK 사용
  • 사용자 추적
  • 앱 사용 행동 분석을 위한 원격 이벤트 수집
  • 계정 생성, 로그인, 서버 동기화
  • 사용자 연락처 전체 접근

6. 삭제 방법

  • 앱 안에서 카드와 노트를 삭제할 수 있습니다.
  • iOS에서 앱을 삭제하면 기기 안의 앱 데이터도 함께 삭제됩니다.
  • 파일 앱에 저장된 백업 ZIP은 사용자가 직접 삭제해야 합니다.

7. 변경

앱 기능이 바뀌어 데이터 처리 방식이 달라지면 이 개인정보 처리방침을 갱신합니다. 예를 들어 계정, 서버 백업, 사용 통계, 광고 기능을 추가하는 경우 App Store 정보와 이 문서를 함께 갱신합니다.
